# DocSync v1.18 local snapshots

Snapshots are local ZIP files at `accounts/<user>/snapshots/`, outside the live workspace. They contain `manifest.json`, a SQLite backup made with `sqlite3.Connection.backup()`, and persistent `originals/` and `generated/` data. They exclude renders, logs, temporary data, SQLite WAL/SHM files, account authentication data, settings, and snapshot/restore directories.

The manifest schema is version 1 and carries snapshot/user/device UUIDs, creation time, DocSync/database versions, local workspace revision, sizes, and hashes for every included file. Archives are SHA-256 hashed after verification. Only the latest two completed snapshots are retained.

Restore first verifies archive hash, manifest, account ownership, ZIP paths/types/sizes, file hashes, and SQLite integrity/schema. It extracts only to `restore-temp`, then promotion keeps `pre-restore-backup` until the replacement activates. A failed activation restores the previous workspace.
