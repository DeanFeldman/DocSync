# DocSync v1.16.0 manual testing

1. **Business document:** upload a formatted agreement, edit a body paragraph,
   stage it, Preview All, Apply, and open the generated DOCX in Word.
2. **Complex table/form:** verify supported table fields map correctly while
   blank decorative or ambiguous areas remain read-only.
3. **Header/footer:** confirm supported header/footer text is preserved and can
   be staged safely when mapped.
4. **Large document:** verify loading, rendering, staging, preview, and
   generation remain usable without unexpected editable regions.
5. **Multi-document set:** find repeated wording across documents, combine it
   with a Layout edit, Preview All, and verify one generated version per
   affected document.
