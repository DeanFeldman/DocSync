# DocSync v1.16.0 release notes

## Real-document compatibility and reliability

v1.16 adds a repeatable compatibility harness for representative Word
structures: formatted and run-split paragraphs, lists, merged/repeated tables,
headers/footers, and protected or unsupported content from the existing
exhaustive inventory fixture.

The harness measures safe editable/read-only boundaries while validating each
fixture remains a valid DOCX package. It deliberately treats ambiguous drawings,
text boxes, protected field results, and decorative structures as read-only.
This release makes no unsafe mapping guesses.

The initial measured corpus parses and validates 4/4 fixtures with zero unsafe
mappings. Existing mixed batch tests continue to cover Preview All and
one-version-per-affected-document generation.
