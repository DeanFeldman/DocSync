# DocSync v1.11.0 Batch Find & Replace manual acceptance

Use three related real-world Word documents containing repeated company names,
dates, addresses, headings, ordinary and nested tables, all header/footer
variants, hyperlinks, footnotes/endnotes, text boxes, fields, images, comments,
content controls, tracked changes, and at least one shape with DrawingML text.

1. Create a workspace and run Find for the repeated company name.
2. Count every visible occurrence in Word and compare DocSync's total, editable,
   and read-only counts. Enable comments and historical deletions and repeat.
3. Verify multiple hits in one paragraph are individual results and phrases
   split across bold/italic/hyperlink runs are found.
4. Select a subset across all documents and add it to pending changes.
5. Preview a manual rich-editor clause change and add it to the same batch.
6. Find/replace the address and add a third pending operation.
7. Disable one occurrence, disable/re-enable one operation, modify one
   replacement, and confirm all survive an application restart.
8. Preview all. Intentionally add overlapping replacements and confirm Apply is
   blocked until the conflict is removed.
9. Apply the clean batch and watch document-count progress in the background.
10. Confirm each affected document has exactly one new immutable version and
    each unaffected document has none.
11. Open every output in desktop Microsoft Word. Confirm selected changes,
    unselected text, run formatting, hyperlink destinations, tables, nested
    tables, header/footer linking, notes, fields, images, text boxes, content
    controls, comments, tracked markup, and shapes remain structurally correct.
12. Confirm field results/instructions, tracked deletions, and DrawingML text are
    reported read-only and were not changed.
13. Download the generated set and individual versions.
14. Restart DocSync; confirm search, batch history, version history, preview, and
    downloads remain correct.
15. Restore an older version and confirm restore creates a new current version.

Record the Word version, fixture names, visible/manual counts, generated version
IDs, and any compatibility warning. Microsoft Word compatibility is not proven
by OPC validation alone.
