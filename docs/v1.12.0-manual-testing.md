# DocSync v1.12.0 layout and blank-field manual acceptance

Use a real Word agreement containing numbered clauses, a table of contents,
repeated wording, paragraphs crossing page boundaries, blank signature lines,
ordinary empty bordered cells, merged cells, headers, footers, and at least one
nested table or protected drawing.

1. Open the document in Layout and enable selectable areas.
2. Confirm numbered clauses, TOC entries, repeated wording, and cross-page
   paragraphs are highlighted in their real rendered positions.
3. Confirm every visible signature underline has exactly one selectable region.
4. Select an empty bordered table cell, enter a value, preview, and generate.
5. Select a blank merged cell, enter two lines with Enter, apply inline italic or
   bold formatting, preview, and generate.
6. Paste multiline plain text into another supported cell and confirm the line
   breaks remain in the draft and generated DOCX.
7. Open every generated file in desktop Word and confirm the table geometry,
   merges, borders, surrounding cells, wrapping, and pagination remain valid.
8. Confirm nested tables and cells containing protected drawings remain
   explicitly read-only.
9. Confirm there is no `Select from structure` button or synthetic layout.
10. Force a Word preview failure, confirm the real preview reports the failure,
    then close the blocking Word dialog and retry successfully.
11. Start with a schema-8 copy of a large workspace. Confirm a verified backup is
    created, schema 9 completes within the desktop startup limit, and existing
    element/revision identities are unchanged.
12. Restart DocSync and confirm schema 9 is not rerun and no blank field is
    duplicated.
13. Download and restore versions, then confirm blank fields remain editable in
    the current restored version.

Record the Word version, fixture name, expected and actual selectable-region
counts, migration duration, generated version IDs, and any Word compatibility
warning. OPC validation alone does not prove Microsoft Word compatibility.
