# DocSync v1.5.0 release notes

DocSync v1.5.0 adds paragraph-level editing for supported Microsoft Word table
cells. A cell with several paragraphs is no longer treated as one replacement
unit: each non-empty direct paragraph has its own stable selection, formatting,
matching, preview, and write-back target.

Large pre-v1.5 workspaces are upgraded with cached DOCX structure and style
lookups so the one-time table-paragraph migration stays within the desktop
startup window.

## Table-paragraph editing

- Top-level table cells are deduplicated by physical Word cell identity.
- Every non-empty direct cell paragraph is emitted as `table_paragraph` with a
  zero-based table, row, column, paragraph, and document-order location.
- Layout and Edit display one selectable block per table paragraph and a
  one-based location label for users.
- Selecting a supported Layout block opens Edit, loads the same immutable block
  into Quill, and moves keyboard focus to the editor.
- Bold, italic, underline, alignment, and safely represented ordered/unordered
  list indentation round-trip through Quill Delta and DOCX paragraph runs.
- Enter is blocked, multiline paste is flattened to one paragraph, and the API
  rejects structural Delta operations or multiline replacement content.
- Heading formatting is hidden and rejected for table paragraphs.

## Matching, preview, and generation

- Exact and near matching require a compatible `table_paragraph` type, which
  prevents identical body wording from becoming an automatic table target.
- Near matches continue to show a score and word-level changes and require an
  explicit confirmation.
- Shared wording, per-document values, and paragraph override modes work with
  table paragraphs.
- Preview is side-effect free and reports document name, source version, edit
  mode, table, row, column, paragraph, before text, and after text.
- Generation writes the exact paragraph without replacing sibling paragraphs or
  reconstructing the cell. It preserves unrelated table XML and creates a new
  immutable version.
- Existing stale-version checks, batch transaction boundaries, history,
  downloads, and restore behavior apply unchanged.

## Unsupported table structures

Merged cells, nested tables, drawings, embedded objects, fields, hyperlinks,
tracked changes, comments, and other unsafe cell structures remain preserved
and read-only. The structured UI gives a plain-language explanation and does not
offer an enabled edit action. Empty cell paragraphs are omitted.

This release does not add or delete rows, columns, cells, or paragraphs; merge
or split cells; resize or move table structures; edit nested tables; or change
borders, shading, and layout.

## Workspace migration

Schema migration 2 reparses each stored immutable DOCX version and regenerates
legacy whole-cell mappings as paragraph-level snapshots. Before migration of a
persisted workspace, DocSync creates and integrity-checks a timestamped SQLite
backup under `workspace/migration-backups`. A failed migration restores the
active database and does not record the schema marker.

## Verification

Automated coverage includes paragraph and document ordering, duplicate merged
cell suppression, rich Delta extraction, exact/near table matching, body/table
match separation, search, preview metadata, per-document generation, sibling
paragraph and formatting preservation, merged/nested/drawing read-only states,
immutable history, migration backup/regeneration, and existing stale/atomic
rollback behavior.
