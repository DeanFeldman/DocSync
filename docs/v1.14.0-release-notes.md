# DocSync v1.14.0 release notes

## Unified Pending Changes

Find & Replace now stages selected occurrences into the same durable Pending
Changes batch as direct Layout edits. A batch can combine both operation types,
remove individual operations or occurrences, and be cleared without changing a
DOCX.

Eligible Find & Replace occurrences now appear as temporary replacements over
the immutable Layout preview. The overlay uses the existing render map and
cached document data; staging, removing, and clearing changes never regenerates
Word or modifies the PDF.

Preview All resolves the complete mixed batch without writes. Apply remains the
only generation step and creates one immutable DOCX version per affected
document, preserving the existing conflict, stale-version, history, and rollback
protections.
