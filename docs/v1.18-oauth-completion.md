# OAuth completion page deployment

Deploy the public completion page with `supabase functions deploy docsync-auth-complete --no-verify-jwt`. Add `https://<project-ref>.supabase.co/functions/v1/docsync-auth-complete` to Supabase Auth Redirect URLs. The desktop defaults to this URL from `VITE_SUPABASE_URL`; set public `VITE_AUTH_COMPLETION_URL` only when using an equivalent HTTPS endpoint. The page never exchanges the code or accesses tokens; it validates the code and opens `za.co.docsync://auth/callback`.
