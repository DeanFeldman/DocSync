# v1.18.0 manual testing

For local snapshot testing, create a workspace with documents, create a snapshot, and inspect its ZIP: it must contain `manifest.json`, `workspace/docsync.db`, `workspace/originals/`, and required `workspace/generated/` files, but no auth session, `.env`, preview render, log, or snapshot files. Change one archive byte and confirm hash verification rejects it. Attempt restore as a different account, and with a ZIP-slip path, corrupt SQLite database, missing manifest, or unsupported manifest version; each must leave the active workspace unchanged.
