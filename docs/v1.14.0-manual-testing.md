# DocSync v1.14.0 manual testing

## A. Find & Replace

1. Find `Acme Holdings` across two documents, select only a subset, and stage
   the replacements as `Acme Group`.
2. Open each affected Layout page and confirm the pending replacement overlays
   the immutable source text without a new version being created.
3. Open Pending Changes, Preview All, and Apply. Confirm one new DOCX version
   per affected document contains all selected replacements.

## B. Mixed edits

1. Stage a Find & Replace occurrence, then make a direct Layout edit in the
   same document.
2. Confirm both appear in Pending Changes and their Layout overlays remain
   visible. Preview All and Apply.
3. Confirm the generated DOCX contains both changes and only one new version
   was created for the document.

## C. Conflict

1. Stage overlapping Find & Replace operations, or a Find & Replace occurrence
   and a direct edit targeting the same block.
2. Preview All and confirm the conflict is shown and Apply is blocked.
