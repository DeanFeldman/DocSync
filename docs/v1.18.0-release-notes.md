# DocSync v1.18.0

## Edit Word files in DocSync

- Open DOCX files in embedded ONLYOFFICE. Rename files, download saved versions, and restore an earlier version from the file list.
- Save to **Matching files** to share eligible wording edits, paragraph additions and deletions, and list items. Use **This file only** for local edits. The toolbar reports saved files and identifiable skipped matches.
- A whole table can be deleted from exact matches. Where a corresponding table contains file-specific text, use **Review table deletions** to select the files where the entire table should be removed.

## Keep workspaces on this device

Open DocSync without signing in. Use **Local data** to export a complete workspace ZIP or to review and import a ZIP you transferred from another device. Existing workspaces and earlier document versions remain available.

## Windows setup

Install and configure the local ONLYOFFICE Docs service before editing. The Windows installer includes a PowerShell launcher for a configured WSL 2 service. Follow the [Windows setup guide](https://github.com/DeanFeldman/DocSync/blob/v1.18.0/docs/local-onlyoffice-windows.md).
