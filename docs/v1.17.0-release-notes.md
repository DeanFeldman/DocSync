# DocSync v1.17.0 release notes

v1.17 requires Google sign-in through Supabase Auth before a DocSync workspace
is opened. The desktop flow uses PKCE, a system browser, an exact DocSync
callback, and Electron safeStorage for encrypted session persistence. Sessions
restore on reopening and can be cleared with sign-out.

Documents remain local: document content is not uploaded as part of this
account foundation. Usage telemetry is not included yet. This release does not
add subscriptions, cloud document storage, or account-management features.
