# DocSync v1.18.1

- Launch DocSync from the normal Windows shortcut. After initial setup, DocSync starts or reuses the local ONLYOFFICE Docs service automatically. [#57](https://github.com/DeanFeldman/DocSync/issues/57)
- The editor shows progress while the local service starts and offers a setup guide and retry if it cannot connect.

If ONLYOFFICE Docs is already configured on this computer, open DocSync as usual after installing the update. For a new machine, follow the [Windows setup guide](https://github.com/DeanFeldman/DocSync/blob/v1.18.1/docs/local-onlyoffice-windows.md).
