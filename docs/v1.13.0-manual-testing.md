# DocSync v1.13.0 manual acceptance

Use a real Word agreement with repeated wording, an editable Layout paragraph,
qualified blank form lines, and a supported table field.

1. In Layout, edit a paragraph and wait for **Pending**. Click elsewhere and
   confirm the document page itself still shows the pending replacement.
2. Reopen that paragraph, confirm the staged value is loaded, edit again, and
   confirm one pending operation is updated rather than duplicated.
3. Stage two more direct Layout edits. Scroll and switch documents; confirm all
   pending overlays persist. Remove one operation and confirm only its base PDF
   text returns. Clear the batch and confirm all overlays disappear.
4. Preview All. Confirm before text is the immutable Word value and after text
   is the staged replacement. Apply All, then confirm the refreshed Word render
   contains the new text without a duplicate pending overlay.
5. Select bordered/underlined blank body form lines, including stacked lines.
   Confirm each maps once to a real writable target; confirm ordinary spacer
   paragraphs and decorative rules remain non-editable.
6. Set appearance to Light, Dark, and System. Restart the desktop application
   after each choice and confirm the preference is retained.

Record the Word version, fixtures, screenshots, expected/actual mapped form
line counts, generated version IDs, and any Word compatibility warnings.
