# v1.16.0 document compatibility evidence

The repeatable compatibility corpus contains four synthetic DOCX fixtures: core
paragraphs/lists with split and formatted runs, merged/repeated table content,
header/footer content, and the existing exhaustive inventory fixture containing
protected and unsupported structures.

| Metric | Result |
| --- | ---: |
| Corpus documents parsed and ZIP-validated | 4/4 |
| Fixtures with safe editable regions | 4/4 |
| Unsafe mappings | 0 |
| Unsupported/protected regions exposed read-only | 1 fixture |

The harness validates that each fixture is a readable DOCX package, parses it
through the production text inventory service, records mapped/editable/read-only
block counts, and asserts that unsupported content remains read-only. Existing
batch-generation regression coverage verifies Preview All and one immutable
version per affected document for mixed multi-document changes.

Known boundaries remain deliberate: drawings, text boxes, protected field
results, and ambiguous decorative structures are preserved but not editable.
