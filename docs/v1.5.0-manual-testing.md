# DocSync v1.5.0 manual Microsoft Word test checklist

Use copies of representative documents. Keep the original uploads available for
binary and visual comparison; DocSync must never overwrite them.

## Test document matrix

Prepare at least two related DOCX files containing:

- a simple two-column table with several rows;
- two or more paragraphs in one cell;
- bold, italic, and underlined runs in table paragraphs;
- an ordered list and an unordered list in cells;
- exact table wording shared across documents;
- similar but non-identical table wording;
- a horizontally or vertically merged cell;
- a nested table;
- an empty cell and empty cell paragraph;
- an image in a cell;
- a table between normal body paragraphs;
- identical wording once in a body paragraph and once in a table paragraph.

## Selection and editing

1. Open Layout and confirm table paragraphs appear in DOCX order with Table,
   Row, Column, and Paragraph labels.
2. Select each paragraph from a multi-paragraph cell. Confirm Edit opens the
   exact block, displays the same location, and focuses Quill.
3. Edit only the first paragraph. Exercise bold, italic, underline, alignment,
   list type, and indentation where applicable.
4. Confirm Enter does not split the block and multiline paste becomes one
   paragraph.
5. Exercise Undo and Redo. Select another paragraph, document, and version and
   confirm prior draft history is no longer applied.

## Match and preview

1. Confirm the matching table paragraph appears as an exact target in the other
   document.
2. Confirm identical body wording is not an automatic table target.
3. Open Compare, verify the near-match score and word-level differences, and
   confirm it is excluded until explicitly approved.
4. Exercise Shared wording, Per-document values, and Paragraph override.
5. Confirm preview shows document name, source version, edit mode, full table
   location, original text, and replacement text for every target.

## Generation and preservation

1. Generate the reviewed operation and confirm new immutable versions appear in
   history while the original uploads remain unchanged.
2. Download every changed DOCX and open it in the supported Microsoft Word
   version on Windows 10 or Windows 11.
3. Visually compare it with the source. Confirm sibling cell paragraphs, other
   cells and rows, borders, dimensions, widths, shading, images, list layout,
   and unrelated formatting remain present.
4. Confirm the intended paragraph text and supported formatting changed.
5. Download the generated version, restore the earlier version, and continue
   editing from the restored current version.

## Read-only and conflict behavior

1. Confirm merged, nested, and image/object cells remain visible and display a
   clear read-only reason without an enabled edit action.
2. Search for supported table text and confirm the result opens the correct
   document version and paragraph.
3. Open a preview, create another version of one target document, then submit
   the old generation request. Confirm `409 Conflict`, no head advancement, and
   no partial output.
4. Force one target write to fail in a multi-document operation. Confirm no
   document head advances, no incomplete current version appears, staged files
   are removed, and previous downloads remain valid.

Record the Word version, Windows version, fixture names, generated version IDs,
and pass/fail evidence for release sign-off.
