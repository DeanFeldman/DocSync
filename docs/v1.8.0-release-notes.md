# DocSync v1.8.0 release notes

## Inline editing in Word Layout

DocSync v1.8.0 combines high-fidelity Word layout, direct safe selection, and
the existing controlled editing workflow in one Layout workspace.

### Background preview jobs

- **Load Word Preview** now queues a durable job and returns control quickly.
- Word exports run one at a time for COM safety and reuse a complete cached PDF
  only for the exact immutable version.
- Queued, Word startup, opening, PDF rendering, display, mapping, ready, and
  failed stages remain visible without blocking navigation.
- Controlled page images appear before contextual coordinate matching
  completes. A preview failure leaves structured Layout and Edit available.

### Controlled preview and safe mapping

- Replaced the browser PDF iframe with a controlled multi-page viewer using
  PyMuPDF page images, page dimensions, nearby-page mounting, zoom, fit width,
  fit page, scrolling, and resize-aware normalized overlays.
- Added version/source/PDF-bound render-map caches and page-image endpoints.
- Added multi-line and repeated-text mapping with a `0.90` interactive
  threshold. Ambiguous or overlapping candidates never become editable.
- Added hover, focus, selected, persistent-area, and read-only states with
  accessible location labels and reasons.

### Inline Quill and operation sidebar

- Clicking a safe region remains in Layout and opens a restricted Quill editor
  over the paragraph with an approximate click-position caret.
- Prevented new paragraphs and flattened multiline paste. Escape returns focus
  to the selected region; Tab, Enter, and Space support keyboard use.
- Reused the same draft, formatting, Undo/Redo, exact matches, near-match
  decisions, editing modes, targets, preview, and generation operation used by
  structured Edit.
- Added fixed-snapshot and overflow messages so browser editing never implies
  final Word pagination.

### Generation and safety

- Successful generation queues new previews for all result versions after the
  atomic document commit. Safe active views follow and rerender the new
  immutable version; unrelated dirty drafts keep their existing protection.
- Fields, images, shapes, text boxes, watermarks, content controls, tracked
  changes, comments, and unsupported structures remain preserved/read-only.
- Structured Edit and **Select from structure** remain supported fallbacks.

### Storage and packaging

- Added schema migration 5 and the durable `preview_render_jobs` table.
- Added PyMuPDF 1.28.0 to runtime and PyInstaller packaging.
- Updated package, web, and API versions to `1.8.0`.

Automated coverage includes job acceptance/cache/failure/retry, progressive
page readiness, mapping safety, migrations, frontend integration contracts,
and the existing editor/generation suite. The separate Microsoft Word manual
gate is recorded in [the manual plan](v1.8.0-manual-testing.md).
## Direct Selection in Word Preview

DocSync v1.8.0 adds direct selection to the high-fidelity preview while keeping
Microsoft Word's PDF output as the layout authority. The PDF appears first.
DocSync then extracts text geometry in a bounded background worker, matches it
to immutable structured blocks, and replaces the native PDF surface with
controlled page images and normalised HTML overlays when the map is ready.

### Preview selection

- Reliably mapped headings, body paragraphs, list items, table paragraphs,
  headers, and footers open their exact structured block in Edit.
- Multi-line and cross-page blocks use multiple regions with the same element
  ID.
- Linked header/footer page occurrences resolve to the one deduplicated physical
  part already used by the editor.
- Region activation reuses current-version validation, read-only checks, draft
  protection, Edit-mode switching, Quill Delta loading, and editor focus.
- Editable and read-only regions are keyboard focusable. Enter and Space
  activate editable regions; accessible labels include type, page, location,
  text preview, and state.

### Alignment and display

- Coordinates use at least six decimal places and are normalised to page width
  and height.
- Zoom in/out, fit width, fit page, window/sidebar resizing, and horizontal or
  vertical scrolling preserve page-relative alignment.
- Transparent overlays become visible on hover or focus. Selected regions stay
  highlighted, read-only regions use a distinct non-editable treatment, and
  **Show selectable areas** reveals the full reliable map.
- Page images and overlays are mounted only for visible and nearby pages.
- Rotation is not exposed on the controlled direct-selection surface.

### Mapping safety and cache identity

- PyMuPDF 1.28.0 extracts page dimensions, words, line geometry, and page
  images from the exact Word-generated PDF.
- Mapping combines text, full-line boundaries, element type, header/footer
  page band and variant, immutable document order, duplicate cardinality, and
  overlap detection. Text alone never resolves an ambiguous duplicate.
- Unique contextual matches score 0.99, ordered one-to-one duplicates score
  0.95, and repeated header/footer occurrences score 0.97. The configurable
  interactive threshold defaults to 0.90.
- Ambiguous, overlapping, missing, or below-threshold mappings never become
  editable. Reliably located unsupported Word content remains read-only.
- JSON maps are keyed to document/version identity, source SHA-256, PDF
  SHA-256, PDF file fingerprint, Word/PDF engine, mapper algorithm/version,
  DPI, page count, and render ID. A regenerated PDF or new/restored immutable
  version cannot reuse stale coordinates.

### API and status

- `GET /api/document-versions/{version_id}/render-map` returns
  `not_requested`, `queued`, `processing`, `completed`, `partial`, or `failed`.
- `GET /api/document-versions/{version_id}/render-pages/{render_id}/{page}.png`
  serves only a page belonging to the current validated map for that immutable
  version.
- PDF success and map success are independent. A failed or partial map leaves
  the Word PDF visible and **Select from structure** available.
- No database migration is required; maps and page images are disposable JSON
  render-cache artifacts.

### Configuration

```text
DOCUMENTSYNC_RENDER_MAP_CONFIDENCE_THRESHOLD=0.90
DOCUMENTSYNC_RENDER_MAP_DPI=144
DOCUMENTSYNC_RENDER_MAP_MAX_PAGES=500
```
