# DocSync v1.17.0 manual testing

1. Open DocSync, choose **Sign in with Google**, and confirm the system browser opens.
2. Choose a Google account. Google returns to Supabase, which redirects to
   `za.co.docsync://auth/callback`; confirm the existing window receives and
   focuses for the callback (and that a new instance passes it to the open one).
3. Confirm the signed-in identity appears. Close and reopen DocSync: the session
   should restore without opening the browser.
4. Sign out, restart DocSync, and confirm it remains signed out. Local documents
   and all normal document editing must remain intact.
5. Temporarily make Supabase unreachable and confirm local document workflows
   remain usable; account sign-in may show an error without affecting documents.
