# DocSync v1.15.0 release notes

## Download analytics foundation

DocSync now keeps daily snapshots of public GitHub Release installer download
counts. A scheduled GitHub Action collects the cumulative counts using the
GitHub Releases API, records each installer asset independently, calculates
daily changes, and commits the durable history back to this repository.

The stored data is in `analytics/download-history.csv`; generated headline
metrics are in `analytics/summary.json`, with a readable summary in
`analytics/README.md`. Counts represent asset downloads, not unique users,
installs, or active users. Checksum files and source archives are excluded.

No in-app telemetry is collected or transmitted. The collector reads only
public GitHub Release asset statistics.
